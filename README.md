# Karuva Tech Portfolio 🚀

Welcome to the official repository for Karuva Tech, a digital agency specializing in high-end, minimalist, and responsive web experiences. 

This project showcases my journey as a Front-End Developer and Digital Creator, highlighting my technical stack and commitment to clean, "calm girl" aesthetic design.

## 🔗 Live Demo
Check out the live site here: https://karuva-tech-portfolio.vercel.app/

## 🛠️ Technical Stack
*   HTML5 - Semantic structure for SEO and accessibility.
*   CSS3 - Custom styling featuring Glassmorphism and responsive layouts.
*   JavaScript - Interactive elements and smooth navigation.
*   Formspree - Integrated serverless contact form handling.
*   Vercel - High-performance hosting and deployment.

## ✨ Key Features
*   Mobile-First Design: Fully responsive layout optimized for all devices.
*   Clean Aesthetic: Minimalist UI/UX designed for a premium user experience.
*   Secure Links: Implemented `rel="noopener noreferrer"` for safe external navigation.
*   NGO Focus: Includes sections dedicated to civic education and social impact projects.
